📊 Sales Data Analyzer

A Python-based Sales Data Analysis and Visualization project that helps users explore CSV datasets, handle missing values, generate descriptive statistics, and create visualizations.

🚀 Features

- Load CSV datasets using Pandas.
- Explore rows, columns, and data types.
- Handle missing values.
- Generate descriptive statistics, variance, and standard deviation.
- Create 6 types of plots using Matplotlib and Seaborn.
- Save visualizations as image files.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

⚙️ Installation & Usage

1. Install the required libraries:
   
   pip install pandas numpy matplotlib seaborn

2. Run the Python file:
   
   python main.py

3. Enter the path of your CSV dataset and select options from the menu.

📈 Visualizations

- Bar Plot
- Line Plot
- Scatter Plot
- Pie Chart
- Histogram
- Stack Plot

🎯 Objective

To practice Python data analysis, data cleaning, statistical calculations, and data visualization through a menu-driven application.
